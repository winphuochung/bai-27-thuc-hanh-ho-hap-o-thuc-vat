# Web/app học tập — Khoa học tự nhiên 7, Bài 27

**Bài 27: Thực hành: Hô hấp ở thực vật**
Môn Khoa học tự nhiên 7 — Chương trình GDPT 2018, sách Kết nối tri thức với cuộc sống
(Chương VII: Trao đổi chất và chuyển hóa năng lượng ở sinh vật; SGK tr. 116–117).

Giáo viên: Lê Văn Thắng — Trường TH và THCS Phước Hưng, xã Nhơn Hội, tỉnh An Giang.

## Nội dung

Web/app học tập 6 phần: Khởi động, Khám phá, Mô phỏng, Sơ đồ tư duy, Luyện tập (10 câu trắc nghiệm tự chấm), Vận dụng.

Mô phỏng thí nghiệm hô hấp ở thực vật (hình SVG nội tuyến thay đổi theo từng bước):
học sinh sắp xếp đúng 5 bước — bố trí chuông A (đĩa hạt nảy mầm + cốc nước vôi trong),
bố trí chuông B đối chứng (chỉ cốc nước vôi trong), đậy kín 2 chuông, chờ 30 phút
(hạt thải bọt khí CO2), quan sát sau 1 giờ (cốc A vẩn đục trắng, cốc B không đổi) —
rút ra kết luận: hạt nảy mầm có hô hấp tạo ra khí carbon dioxide.

## Cách dùng

- Mở file `index.html` bằng trình duyệt bất kì (không cần máy chủ).
- Học sinh đăng nhập bằng Họ tên + Lớp, học 6 phần, làm 10 câu trắc nghiệm rồi nộp bài.
- Điểm tự động lưu về Google Sheets của giáo viên (qua Apps Script Web App, chạy bằng tài khoản giáo viên).

## File trong repo

- `index.html` — web/app hoàn chỉnh, tự chứa (hình ảnh nhúng base64).
- `Web_Hoc_Tap_KHTN7_Bai27.md` — bản sao toàn bộ mã nguồn kèm khóa đáp án.
- `Code.gs` — Apps Script Web App ghi điểm về Google Sheets (tab KetQua).
- `assets-flow/` — 3 ảnh nền (đăng nhập, chính, hero) + logo cá nhân.
- `README.md` — file này.
